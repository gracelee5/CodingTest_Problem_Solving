# CodingTest_Problem_Solving
코딩테스트 문제 풀이 기록입니다.

## 사용 언어
JavaScript

## 플랫폼
- 프로그래머스 (메인)
- 백준

## 폴더 구조
- `/programmers` - 프로그래머스 문제별 풀이
- `/baekjoon` - 백준 문제별 풀이

## 주요 학습 카테고리
- 자료구조: 배열, 스택/큐, 해시, 힙
- 알고리즘: 완전탐색, DFS/BFS, 정렬, 이분탐색, DP, 그리디

## 풀이 방식
- 꾸준히 풀이를 기록하며, 풀지 못한 문제는 풀이 후 다시 작성하여 학습합니다.
- ([블로그](https://velog.io/@gracelee5/series/%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%A8%B8%EC%8A%A4))에 핵심 풀이 정리를 함께 작성합니다.
